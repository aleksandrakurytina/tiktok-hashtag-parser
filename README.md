# TikTok parser по хештегам (аналитика, только чтение)

Собирает **публичные** данные видео по хештегам (`#работа`, `#заработок`, `#удаленка` …) и складывает в CSV / JSON / XLSX со сводкой по нише.

> Никаких комментариев, лайков, подписок и рассылок. Только чтение открытых страниц.
> Массовый постинг рекламных комментариев под чужими видео = бан аккаунтов и жалобы,
> причём выхлоп там околонулевой. Для привлечения людей работает контент на своём канале,
> а не спам в чужом.

## Установка

### Windows — одним кликом

Запусти `setup.bat` (создаст `.venv`, поставит зависимости и скачает Chromium), потом `run_example.bat`.

### Вручную — Linux / macOS

```bash
git clone https://github.com/aleksandrakurytina/tiktok-hashtag-parser.git
cd tiktok-hashtag-parser
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m playwright install chromium
```

### Вручную — Windows

```bat
python -m venv .venv
.venv\Scripts\activate.bat
python -m pip install -r requirements.txt
python -m playwright install chromium
```

> Команда `playwright install` без `python -m` на Windows обычно не работает — это нормально, вызывайте её как модуль.

## Быстрый старт

```bash
# Проверка пайплайна без интернета, на тестовых файлах
python tt_parser.py --demo --tags работа,заработок --limit 6

# Боевой запуск (браузер без окна)
python tt_parser.py --tags работа,заработок,удаленка --limit 30 --out out

# Быстрый режим: только ссылки и то, что есть в выдаче, без захода на каждое видео
python tt_parser.py --tags заработок --limit 50 --no-details --format csv
```

Если TikTok показывает капчу или отдаёт пустую выдачу — один раз залогиньтесь:

```bash
python tt_parser.py --save-login session.json     # откроется окно, войдите в аккаунт, Enter
python tt_parser.py --tags заработок --limit 30 --storage-state session.json --no-headless
```

## Все флаги

| Флаг | Смысл |
|---|---|
| `--tags` | хештеги через пробел или запятую, `#` не обязателен |
| `--limit` | максимум видео на тег (по умолчанию 30) |
| `--scrolls` | сколько раз прокрутить выдачу (12) |
| `--delay` | базовая пауза между действиями, сек (2.0) |
| `--out` | папка результатов (`out`) |
| `--format` | `csv`, `json`, `xlsx` или `all` |
| `--no-details` | не открывать страницы видео — быстрее, полей меньше |
| `--min-views` | отсечь видео с меньшим числом просмотров |
| `--storage-state` | файл сессии (см. `--save-login`) |
| `--proxy` | прокси, например `http://user:pass@host:port` |
| `--headless` / `--no-headless` | скрытый / видимый браузер |
| `--demo` | прогнать пайплайн на локальных файлах из `fixtures/` |
| `-v` | подробные логи |

## Что в выдаче

`out/tiktok_<теги>_<дата>.xlsx` — три листа:

- **videos** — все строки: `tag, video_id, url, author, nickname, created_at, duration_sec, views, likes, comments, shares, saves, engagement_rate, hashtags, music, description, collected_at`
- **сводка** — всего видео, уникальных авторов, медиана/средние просмотры, медиана ER, доля видео с ER > 5%, средняя длительность
- **топ по просмотрам / топ по вовлечению** — верхние 30

`engagement_rate` = (лайки + комменты + репосты + сохранения) / просмотры × 100. Считается на лету.

Как читать эти цифры:
1. Смотри **медиану просмотров**, не среднюю — в нише «заработок» один viral-ролик утягивает среднее.
2. **ER выше медианы по выборке** = формат цепляет, даже если просмотров мало. Такие форматы и надо повторять.
3. Длина ролика + время публикации (`created_at`) → в какое время и какой хронометраж залетает.

## Как не словить блок

- Логин (`--save-login`) — самый сильный фактор. Гостевые сессии TikTok режет первыми.
- Держите `--limit` до ~30–50 за прогон и `--delay` не ниже 2 сек. Не запускайте параллельно.
- С дата-центровых IP/VPS TikTok почти всегда показывает проверку — для стабильного сбора нужен резидентский прокси (`--proxy`).
- Если упёрлись в капчу — скрипт сам останавливается и не долбит сайт дальше. Подождите, залогиньтесь, снизьте лимиты.
- Смотрите `--no-headless` при первых запусках: так видно, что реально происходит.

## Если что-то не собирается

| Симптом | Что делать |
|---|---|
| `Executable doesn't exist at ...\chromium_headless_shell-...` | Браузер не скачан: `python -m playwright install chromium` (на Windows — полный путь к python.exe). Если `playwright` «не распознано», это нормально: запускайте его как модуль, через `-m` |
| После установки снова ругается на номер сборки | Версии пакета и браузера разъехались: `python -m pip install -U playwright` → `python -m playwright install chromium` |
| `похоже на капчу/проверку` | `--save-login session.json`, `--no-headless`, меньше `--limit`, прокси |
| Ссылки есть, метрики нулевые | Так и задумано при `--no-details`. Уберите флаг — скрипт зайдёт на каждое видео |
| Совсем ноль ссылок | TikTok поменял разметку. Откройте тег вручную, сохраните страницу (Ctrl+S) и прогоните парсер по ней — см. `fixtures/`, можно подсунуть свой HTML тем же способом |
| `ModuleNotFoundError` | `pip install -r requirements.txt && playwright install chromium` |

Разметку TikTok меняет регулярно, поэтому парсер не завязан на один селектор: он ищет объекты видео по *форме* (есть `stats` + автор) внутри `__UNIVERSAL_DATA_FOR_REHYDRATION__` / `SIGI_STATE`, а ссылки берёт из DOM по шаблону `/@user/video/id`.

## Про правила площадки

Сбор публичных данных для личного исследования — одно, а автоматизация действий от лица аккаунта и коммерческое использование чужих данных — другое. Для коммерции есть официальные пути: **TikTok Research API** (академический/исследовательский доступ), **Display API** и **Commercial Content API**. Плюс готовые сервисы аналитики (Exolyt, Pentos, Keyhole и т.п.), если не хочется поддерживать парсер. Собранную здесь выборку используйте как ориентир по нише, а не как продукт для перепродажи.
